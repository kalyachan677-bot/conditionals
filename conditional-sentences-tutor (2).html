🎯 ภาพรวม Conditional Sentences คืออะไร?

ประโยคเงื่อนไข (Conditional Sentences) คือประโยคที่กล่าวถึงผลลัพธ์ที่จะเกิดขึ้น ถ้า เงื่อนไขหนึ่งเป็นจริง ประกอบด้วย 2 ส่วนหลัก:

If-clause (อนุประโยคเงื่อนไข) + Main clause (ประโยคหลัก/ผลลัพธ์)

ตัวอย่าง: If it rains (ผลลัพธ์)

ประโยคเงื่อนไขแบ่งเป็น 4 ประเภทหลัก ตามความเป็นไปได้ของเหตุการณ์ ว่าเป็นจริงเสมอ เป็นไปได้ หรือไม่เป็นจริง (ในปัจจุบัน/อดีต) ดูภาพรวมในตารางสรุปที่หน้า Cheat Sheet

📚 เนื้อหาทั้งหมดในเว็บนี้

  • บทเรียน 6 บท: Overview, Zero, First, Second, Third, Mixed Conditionals + คำเชื่อมทางเลือก (unless, as long as, provided that)
  • แบบฝึกหัด 3 รูปแบบ: เลือกตอบ (Multiple Choice), กรอกคำ (Fill-in-the-blank), เรียงประโยค (Reorder)
  • แบบทดสอบ 2 ชุด: Pre-test (วัดก่อนเรียน) และ Post-test (วัดหลังเรียน) พร้อมจับเวลา
  • สรุป/Cheat Sheet: ตารางเปรียบเทียบโครงสร้างและการใช้งานทั้งหมด + จุดที่มักสอบ
  • ติดตามผล: บันทึกคะแนนแบบฝึกหัดและแบบทดสอบอัตโนมัติ (บนเครื่องของคุณ)
  • ค้นหา: ค้นหาเนื้อหา/ตัวอย่างได้ทันทีจากช่องค้นหา

👨‍🏫 เหมาะสำหรับ

นักเรียน ม.ปลาย ที่กำลังเตรียมสอบ O-NET / GAT / แอดมิชชัน และครูผู้สอนที่ต้องการสื่อการสอนพร้อมแบบฝึกหัดและเฉลย ใช้ได้ทั้งเรียนด้วยตัวเองและสอนในห้องเรียน

📚บทเรียน Conditional Sentences

คลิกที่บทเรียนที่ต้องการเรียน หรือเรียนตามลำดับจากบนลงล่าง เริ่มจาก Zero → First → Second → Third → Mixed

📋 Pre-test: วัดระดับก่อนเรียน

แบบทดสอบ 10 ข้อ ครอบคลุมทุกประเภท Conditional Sentences มีจับเวลา 15 นาที ทำเสร็จเห็นคะแนนและเฉลยพร้อมคำอธิบาย

  • ข้อสอบ 10 ข้อ แบบเลือกตอบ
  • เวลา 15 นาที (แนะนำให้ทำภายในเวลา)
  • เฉลยละเอียดทุกข้อหลังทำเสร็จ
  • คะแนนบันทึกในหน้า "ผลคะแนน" อัตโนมัติ

📋 Post-test: วัดผลหลังเรียน

แบบทดสอบ 10 ข้อ ความยากใกล้เคียงสอบจริง ครอบคลุม Mixed Conditional และ unless/as long as/provided that ด้วย จับเวลา 15 นาที

  • ข้อสอบ 10 ข้อ แบบเลือกตอบ ระดับยากขึ้น
  • ครอบคลุม Mixed Conditional และคำเชื่อมทางเลือก
  • เวลา 15 นาที
  • เปรียบเทียบกับคะแนน Pre-test ได้ในหน้า "ผลคะแนน"

🔑 จุดที่มักออกสอบ (Exam Tips)

1. รูปกริยาใน If-clause และ Main clause ต้องจับคู่กันให้ถูกประเภท สอบมักให้เติมกริยา — ดูความเป็นไปได้ของเหตุการณ์ก่อน แล้วเลือก Tense ให้ตรงประเภท
2. Second Conditional: ใช้ were แทน was กับทุกประธาน (If I were you, If he were rich) — ข้อนี้ออกบ่อยมาก
3. First Conditional: ใน If-clause ใช้ Present Simple ไม่ใช้ will — "If it rains, I will stay" ไม่ใช่ "If it will rain..."
4. Third Conditional: ใช้ Past Perfect (had + V3) ใน If-clause และ would have + V3 ใน Main clause — ห้ามสลับ
5. unless = if not: "Unless you hurry = If you don't hurry" — อย่าใช้ not ซ้ำในประโยคเดียวกัน
6. Mixed Conditional: เงื่อนไขในอดีต ผลในปัจจุบัน = If + Past Perfect, would + V1 (If I had saved money, I would be rich now)
7. ลำดับ If-clause กับ Main clause สลับกันได้: "If it rains, I'll stay" = "I'll stay if it rains" — ถ้า If-clause อยู่หลัง ไม่ใช้จุดคอมมา

🧠 เทคนิคจำง่าย

จำตาม "ความเป็นจริง"

  • Zero จริงเสมอ (fact) → ทั้งคู่ Present Simple
  • First เป็นไปได้จริงในอนาคต → If + Present, will + V1
  • Second ไม่จริง/จินตนาการ (ปัจจุบัน-อนาคต) → If + Past, would + V1
  • Third ไม่จริงในอดีต (เสียใจ) → If + Past Perfect, would have + V3

จำ "ยิ่งเลื่อนประเภทขึ้น ยิ่งไม่จริง"

Zero = จริงเสมอ → First = น่าจะเป็นจริง → Second = ไม่จริงตอนนี้ → Third = ไม่จริงตั้งแต่อดีต ลำดับความจริงลดลงเรื่อย ๆ

จำคำเชื่อมทางเลือก

  • unless = if ... not (ถ้าไม่)
  • as long as = ตราบใดที่ (เน้นเงื่อนไข)
  • provided (that) = โดยมีเงื่อนไขว่า (ทางการ)
  • in case = ในกรณีที่ (เตรียมไว้)
  • even if = แม้แต่ถ้า
